# Reference recordings

Two files, gitignored because they are raw audio:

- `girl.wav` — the base voice for V1, V2, V3
- `boy.wav` — the base voice for V4, V5, V6

Record both in one session, on one mic, in one room. Mono, 24000Hz or higher,
no compression, no reverb, no noise gate, no EQ. Pocket TTS reproduces the
recording faithfully, processing included.

Run `voicelab check` on them before doing anything else.
